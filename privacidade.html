Política de Privacidade

Última atualização: janeiro de 2026

Sobre este site

O SolMais é um projeto de portfólio demonstrando uma experiência de e-commerce de energia solar fotovoltaica. Este site não é uma empresa real, não oferece serviços comerciais e não realiza vendas.

Coleta de dados

Este site não coleta, armazena ou processa dados pessoais. Não há:

  • Formulários de cadastro
  • Coleta de nome, e-mail, telefone ou endereço
  • Integração com CRM ou sistemas de vendas
  • Cookies de rastreamento
  • Ferramentas de analytics de terceiros
  • Back-end ou banco de dados

Simulador de economia

O simulador de economia presente neste site é ilustrativo. Os valores exibidos são estimativas baseadas em inputs do usuário (valor da conta, região, redução desejada) e não são enviados a nenhum servidor. Todo o processamento acontece localmente no navegador e é descartado ao fechar a página.

Links externos

Este site pode conter links para o ecossistema ExpoStacker e para sites de referência. Não nos responsabilizamos pelas políticas de privacidade de sites externos.

Contato

Este é um projeto de portfólio. Para questões sobre o projeto, visite o site principal do ExpoStacker.
