Termos de Uso

Última atualização: janeiro de 2026

Natureza do site

O SolMais é um projeto de portfólio de demonstração de uma experiência de e-commerce de energia solar fotovoltaica. Este site:

  • Não é uma empresa real
  • Não oferece serviços comerciais
  • Não realiza vendas ou contratações
  • Não coleta dados pessoais
  • Não possui atendimento comercial

Conteúdo ilustrativo

Todas as informações apresentadas — incluindo depoimentos, planos, preços, estimativas de economia e dados de empresa — são ilustrativas e servem apenas para demonstrar a experiência de usuário de um site de energia solar. Não constituem oferta comercial.

Simulador

O simulador de economia é uma ferramenta ilustrativa. Os valores exibidos são estimativas baseadas em parâmetros genéricos e não representam uma proposta comercial real.

Uso permitido

Você pode navegar, explorar e interagir com este site para fins de avaliação de portfólio. Não é permitido:

  • Utilizar o conteúdo para fins comerciais
  • Apresentar este site como uma empresa real
  • Coletar dados fictícios apresentados como reais

Propriedade intelectual

Este projeto faz parte do ecossistema ExpoStacker. O código e o design são de autoria do mantenedor do portfólio.

Alterações

Estes termos podem ser alterados a qualquer tempo, sem aviso prévio, por se tratar de um projeto de portfólio.
